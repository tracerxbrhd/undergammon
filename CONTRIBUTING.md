# Contributing

Issues and pull requests are welcome at the owner's discretion. This repository
is public-source proprietary software; submitting a contribution does not make it
open source. You must have the right to submit all code and assets. By submitting
material for inclusion, you permit the owner to use the accepted contribution in
the proprietary UNDERGAMMON project. Contact the owner before submitting material
that requires additional terms. Formal contribution terms remain an owner review
item before actively soliciting external code.

Read AGENTS.md and the approved product/architecture documents. Include behavioral
tests, verification results and dependency/license disclosures. Do not submit
secrets, user data or unlicensed assets. External contributions use pull requests;
the repository owner may push directly. Run pnpm build, pnpm lint,
pnpm format:check, pnpm typecheck and pnpm test before submitting.
