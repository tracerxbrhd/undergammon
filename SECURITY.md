# Security reporting

Report suspected vulnerabilities privately using GitHub's **Report a vulnerability** feature in this repository's Security tab when it is available. If private reporting is unavailable, contact the repository owner privately before sharing exploit details; do not include credentials, Telegram authentication payloads, session data or personal data in public issues.

Relevant boundaries include Telegram authentication, sessions, gameplay command validation, match recovery, concurrency, rating and the Coin ledger. Do not test against other players or production accounts without the owner's authorization.

No response-time commitment or paid bounty is currently offered.
