# Security reporting

Report suspected vulnerabilities privately using GitHub's **Report a vulnerability**
feature in this repository's Security tab. The owner must enable private reporting
before public launch. If unavailable, contact the repository owner privately before
sharing exploit details; do not include credentials or personal data in public issues.

Relevant boundaries include Telegram authentication, sessions, gameplay command
validation, match recovery, concurrency, rating and the Coin ledger. Do not test
against other players or production accounts without the owner's authorization.
No response-time commitment or paid bounty is currently offered.
